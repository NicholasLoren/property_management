## Overview

Users are everyone with an account: staff (Super Admins, Managers) and
landlords alike. There's no public sign-up; every account starts as an
invitation from here.

## Viewing users

**Users** lists every account with their role, status, and last active
time.

![The Users list, showing name, email, role, and status columns](/docs-screenshots/users/users-01-index.png)

## Inviting a user

Click **Invite user**.

![The empty Invite user form: Avatar, Name, Email, Role, and password fields](/docs-screenshots/users/users-02-create-empty.png)

Fill in their name, email, and **Role**. Choosing the **Landlord** role
reveals extra fields for ID number, TIN, address, and phone; this is the
same form used by [Landlords → Add landlord](/docs/landlords/overview).

For the password, you can set one yourself, but the normal path is to
**leave it blank**: that emails the person a link to set their own
password, which is what the invite-only login screen refers you to.

![The form filled in with a name, email, and Manager role, password fields left blank](/docs-screenshots/users/users-03-create-filled.png)

Click **Send invite**.

![The users list after inviting someone, showing a confirmation](/docs-screenshots/users/users-04-invited.png)

## Viewing a user

A user's page shows their role, status (**Invited** until they set a
password and sign in, then **Active**), when they last logged in, and when
they joined.

![A user's detail page, showing role Manager and status Invited](/docs-screenshots/users/users-05-show.png)

## Editing or removing a user

Click **Edit** to change their name, email, role, or status, or set a new
password directly.

![The edit user form, pre-filled with the user's current details](/docs-screenshots/users/users-06-edit.png)

The trash icon on any list moves a user to the trash, reversible via
**Undo** immediately after, or from the Trash tab later. This revokes their
access without needing to change a password.
