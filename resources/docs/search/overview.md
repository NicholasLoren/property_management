## Overview

The search box at the top of every page (or the **⌘K** / **Ctrl+K**
shortcut) searches across your whole portfolio at once (properties,
units, leases, tenants, expenses, and more), not just the module you
happen to be on.

## Using it

Click the search bar, or press **⌘K** (**Ctrl+K** on Windows/Linux), and
start typing. Results appear grouped by type as you type, each linking
straight to that record.

![The global search palette open, showing results grouped by Properties, Units, Leases, and Expenses for the query "Docs Demo"](/docs-screenshots/search/search-01-quick.png)

Use the arrow keys to navigate results and **Enter** to open one, or
**Esc** to close the palette.
