## Overview

Landlords are the property owners you manage on behalf of. Every landlord is
backed by a user account with the **Landlord** role — there's no separate
"landlord record" to fill in beyond that.

## Viewing landlords

**Landlords** in the sidebar lists everyone with the Landlord role, along
with how many properties each one owns.

![The Landlords list, showing a table of landlord names, emails, and property counts](/docs-screenshots/landlords/landlords-01-index.png)

Use the search box to filter by name or email.

![The Landlords list filtered by the search term "Rowan", showing one matching result](/docs-screenshots/landlords/landlords-02-search.png)

## Adding a landlord

Click **Add landlord**. This takes you to the same **Add user** form covered
in [Users](/docs/users/overview), with the role already set to Landlord —
adding a landlord and inviting a user are the same action.

## Viewing a landlord's details

Click a row (or the eye icon) to open a landlord's page: contact details,
portfolio-wide stats (properties, units, occupancy, rent collected), income
and expenses, and compliance info (ID number, TIN, address).

![A landlord's detail page, showing contact info, portfolio stats, income/expenses, and compliance fields](/docs-screenshots/landlords/landlords-03-show.png)

Below that, tabs break down everything tied to this landlord: **Properties**,
**Units**, **Tenants**, **Payments**, **Maintenance**, and **Documents** —
each is a filtered view of that module scoped to just this landlord's
portfolio.

![The same page's Payments tab, listing this landlord's payments across all their properties](/docs-screenshots/landlords/landlords-04-payments-tab.png)

To change a landlord's name, email, phone, or role, click **Edit in Users**
— landlord details are edited from the Users module, not from this page.
