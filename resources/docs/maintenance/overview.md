## Overview

Maintenance requests track repair and upkeep work against a specific unit,
from report to completion.

## Viewing requests

**Maintenance** lists every request with its priority, status, and unit.

![The Maintenance list, showing title, unit, priority, and status](/docs-screenshots/maintenance/maintenance-01-index.png)

## Adding a request

Click **Add request**.

![The empty Add request form: Unit, Title, Priority, Status, Assigned to, Cost, Scheduled date, Completed date, Description, and Notes](/docs-screenshots/maintenance/maintenance-02-create-empty.png)

Select the affected **Unit**, give it a short **Title**, and a
**Description** of what's wrong. Priority defaults to Medium and status to
Open — everything else (assignee, cost, scheduling) can be filled in now or
later as the work progresses.

![The form filled in with a unit, title, and description](/docs-screenshots/maintenance/maintenance-03-create-filled.png)

Click **Add request**.

## Viewing a request

A request's page summarizes its priority, status, assignee, schedule, cost,
and description.

![A maintenance request's detail page, showing status badges and a summary panel](/docs-screenshots/maintenance/maintenance-04-show.png)

## Updating a request

Click **Edit** to assign it to someone, change its status as work
progresses (Open → In progress → Completed, or similar), log a cost once
work is done, and attach photos.

![The edit maintenance request form, pre-filled with the request's current details](/docs-screenshots/maintenance/maintenance-05-edit.png)

## Removing a request

The trash icon on any list moves a request to the trash, reversible via
**Undo** immediately after, or restorable from the Trash tab later.
