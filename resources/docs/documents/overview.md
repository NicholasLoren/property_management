## Overview

Documents are files — contracts, certificates, receipts, anything else
worth keeping on record — filed against a property, unit, tenant, or lease.

## Viewing documents

**Documents** lists everything uploaded across your portfolio, with its
category and who uploaded it. Clicking a document's name opens the actual
file in a new tab.

![The Documents list, showing document name, category, and uploaded-by columns](/docs-screenshots/documents/documents-01-index.png)

## Adding a document

Click **Add document**.

![The empty Add document form: Attach to, Record, Title, Category, Notes, and a file upload](/docs-screenshots/documents/documents-02-create-empty.png)

Choose what it's **Attached to** (Property, Unit, Tenant, or Lease), search
for the specific **Record**, give it a **Title** and a **Category**
(configured in [Extras](/docs/extras/overview)), then attach the file
itself. Accepted types are PDF, Word, Excel, and common image formats.

![The form filled in with a property, title, category, and a PNG file attached](/docs-screenshots/documents/documents-03-create-filled.png)

Click **Add document**.

![The documents list right after adding one, showing a confirmation toast](/docs-screenshots/documents/documents-04-uploaded.png)

## Editing or removing a document

Click the pencil icon on any document's row to update its title, category,
notes, or replace the file. The trash icon moves it to the trash — reversible
via **Undo** immediately after, or permanently deletable from the Trash tab.
