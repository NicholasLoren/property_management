## Overview

Messages are in-app communication between team members: a personal note to
one person, or a broadcast to everyone or a whole role. Messaging currently
reaches other Users (managers, admins, landlords with accounts); tenants
aren't message recipients yet.

## Viewing messages

**Messages** has an **Inbox** for what's been sent to you and a **Sent**
tab for what you've sent.

![The Messages inbox, empty, with Inbox and Sent tabs](/docs-screenshots/messages/messages-01-index.png)

## Sending a personal message

Click **New message**. **Personal** is selected by default.

![The empty New message form set to Personal: To, Subject, and Message](/docs-screenshots/messages/messages-02-create-empty.png)

Search for and select a recipient, then write a subject and message.

![The form filled in with a recipient, subject, and message body](/docs-screenshots/messages/messages-03-create-personal-filled.png)

## Sending a broadcast

If you have permission to broadcast, switch to **Broadcast**. Instead of a
single recipient, choose an **Audience**: everyone, or a specific role.

![The New message form set to Broadcast, showing an Audience dropdown instead of a single recipient](/docs-screenshots/messages/messages-04-create-broadcast.png)

## Sending

Click **Send message** (or **Send broadcast**). You land back in your
**Sent** folder with a confirmation.

![The Messages page after sending, showing "Message sent." and the Sent tab now showing 1](/docs-screenshots/messages/messages-05-sent.png)

Messages can't be edited or unsent once sent.
