## Overview

**Extras** are the small, manageable lists that power dropdowns elsewhere
in the app: **Expense categories**, **Income categories**, **Document
categories**, **Property features** (amenities), and **Unit types**.

![The Extras page on the Expense categories tab, listing categories and how many expenses use each](/docs-screenshots/extras/extras-01-expense-categories.png)

Each tab shows how many records currently use each entry, so you can see
the impact before removing one.

![The Unit types tab](/docs-screenshots/extras/extras-02-unit-types.png)

![The Property features tab, listing amenities like Parking and Swimming pool](/docs-screenshots/extras/extras-03-property-features.png)

## Adding an entry

Switch to the relevant tab and click **Add**. Every entry is just a name.

![The Add category form with a single Name field](/docs-screenshots/extras/extras-04-create-filled.png)

![The expense categories list after adding one, showing a confirmation](/docs-screenshots/extras/extras-05-created.png)

## Editing or removing

The pencil icon renames an entry everywhere it's used; the trash icon
moves it to the trash, reversible via **Undo** immediately after or from
that tab's Trash view later. An entry still in use elsewhere can typically
still be removed — existing records keep showing its name, but it won't be
offered as a choice for new ones.
